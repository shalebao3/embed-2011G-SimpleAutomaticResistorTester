# BSP：板级支持

本目录开始承载与板级器件直接相关、但不属于 STM32 片内外设驱动的接口。

当前已加入：

- `bsp_Range.c/.h`：三档量程选择接口
  - PB12：100Ω 逻辑档候选控制线
  - PB13：1kΩ 逻辑档候选控制线
  - PB14：10kΩ 逻辑档候选控制线
  - 高电平表示“请求外部 NPN/MOSFET 驱动对应继电器吸合”
  - 每次切换先全部拉低，再只拉高目标一路（break-before-make）
  - 初始化默认三路全部关闭

这些 GPIO 是当前板级候选映射，后续画原理图/PCB 时允许在本模块集中调整。GPIO **不能直接驱动继电器线圈**，真实硬件必须加入驱动管和续流保护。

ADC 采样仍在 `../Driver/`，电阻换算和量程决策仍由 `../App/` 负责；BSP 只负责把上层的“选择某档”变成具体硬件控制动作。
