# 2011G 简易自动电阻测试仪

基于 **STM32F103C8T6 + STM32F10x 标准外设库** 实现 2011G 简易自动电阻测试仪。

当前项目从通用 STM32F103C8T6 标准库模板创建，现阶段处于：

> **题目需求拆解 + 测量原理分析 + 硬件/软件方案设计阶段**

目前先聚焦基本测量功能，发挥部分暂不展开。

## 2. 当前对测量原理的理解

STM32 的 ADC **不能直接测量电阻**。

真正的测量链路是：

```text
已知参考电阻 Rref
        │
        ├──── 与待测电阻 Rx 构成测量电路
        │
        ▼
产生一个与 Rx 有关的模拟电压
        │
        ▼
STM32 ADC 引脚
        │
        ▼
ADC 得到数字量
        │
        ▼
CPU 根据电压、Rref 和电路关系
反推出待测电阻 Rx
```

因此：

- **ADC 测的是电压**
- **软件算出来的才是电阻值**
- 参考电阻是整个测量电路的重要基准

当前优先考虑使用简单、容易分析的 **电阻分压法** 作为基本测量模型。

具体电路拓扑、参考电阻阻值和精度等级仍需结合题目要求继续确定。

## 3. 为什么需要分量程

如果整个测量范围只使用一个固定参考电阻，会出现严重的动态范围问题。

例如：

- 参考电阻太小，测很大的待测电阻时，ADC 电压可能长期挤在接近满量程的位置
- 参考电阻太大，测很小的待测电阻时，ADC 电压可能长期挤在接近 0 的位置

这两种情况都会导致：

- ADC 有效分辨率下降
- 少量 ADC 误差被放大
- 电阻计算误差增大

所以自动电阻测试仪需要根据被测电阻的大致范围，切换不同的参考电阻，让 ADC 电压尽量工作在一个较合适的区间。

可以类比为：

> 用不同量程的尺子测不同大小的物体，而不是拿同一把尺子同时测头发和房子。

## 4. 自动量程的基本架构

当前讨论确定的核心架构是：

```text
             ┌──── 参考电阻 R1 ────┐
             ├──── 参考电阻 R2 ────┤
GPIO ───────→│    模拟开关/继电器    │
             ├──── 参考电阻 R3 ────┤
             └──── 高阻测量支路 ? ──┘
                        │
                        ▼
                  待测电阻 Rx
                        │
                        ▼
                    测量节点
                        │
                        ▼
                       ADC
                        │
                        ▼
                      CPU
                        │
             判断当前量程是否合适
                        │
                        └────→ GPIO 切换量程
```

这里有一个非常重要的区分：

### ADC：负责“感知”

ADC 把测量节点的模拟电压转换成数字值。

### CPU：负责“判断”

程序读取 ADC 值，根据设定的阈值判断：

- 当前量程是否合适
- 是否需要换更大或更小的参考电阻
- 当前应该使用哪个参考电阻进行最终计算

### GPIO：负责“执行”

GPIO 本身不会读取 ADC 的反馈，也不会计算电阻。

GPIO 只是由 CPU 控制输出高低电平，用于驱动：

- 模拟开关
- 多路复用器
- 继电器
- 其他量程切换电路

也就是说：

```text
ADC = 眼睛
CPU = 大脑
GPIO = 手
```

---

## 5. GPIO 与 ADC 不是串联关系

需要避免下面这种错误理解：

```text
待测电阻 → GPIO → ADC
```

实际情况更接近：

```text
待测电阻 + 参考电阻
        │
        ▼
     模拟电压
        │
        ▼
ADC 模拟输入引脚
```

而 GPIO 输出位于另一条控制链：

```text
CPU
 │
 ▼
GPIO 输出
 │
 ▼
模拟开关 / 继电器
 │
 ▼
选择当前参考电阻
```

STM32 的某些物理引脚既具有普通 GPIO 功能，也具有 ADC 复用功能。

当一个引脚配置为 ADC 模拟输入后，应把它理解成：

> **这个物理引脚现在服务于 ADC，而不是模拟信号先经过普通 GPIO 再进入 ADC。**

---

## 6. 自动换挡不是等 ADC “溢出”

自动量程不应该等 ADC 真正到达 0 或满量程后才处理。

更合理的做法是设置：

- ADC 下阈值
- ADC 上阈值

例如抽象为：

```text
ADC 太低
    ↓
当前参考电阻/量程不合适
    ↓
切换量程

ADC 落在有效区间
    ↓
保持当前量程
    ↓
计算最终电阻

ADC 太高
    ↓
当前参考电阻/量程不合适
    ↓
切换量程
```

最终阈值不能现在拍脑袋确定，需要在电路、ADC 参考电压、参考电阻和目标精度确定之后再计算。

### 推荐的软件流程

```text
选择初始量程
    ↓
等待模拟电路稳定
    ↓
ADC 采样
    ↓
判断 ADC 是否进入有效区间
    │
    ├── 否 → GPIO 切换量程 → 重新采样
    │
    └── 是
         ↓
根据当前 Rref 计算 Rx
         ↓
滤波 / 修正
         ↓
显示结果
```

## 7. 当前涉及的 STM32 外设

### 7.1 ADC —— 核心外设

ADC 是本题最核心的新外设。

主要职责：

- 采集电阻测量电路产生的模拟电压
- 为自动量程判断提供输入
- 为最终电阻计算提供原始数据

当前阶段优先使用：

> **软件触发 ADC**

原因是电阻测量的刷新频率很低，没有必要一开始就引入复杂的定时器硬件触发。

---

### 7.2 GPIO 输出 —— 自动量程

GPIO 输出主要负责：

- 选择参考电阻
- 控制模拟开关或继电器
- 完成自动换挡

GPIO **不直接负责测量电阻**。

---

### 7.3 GPIO 输入 / EXTI —— 可选

如果后续题目需要按键，例如：

- 功能切换
- 参数设置
- 筛选模式
- 手动操作

可以使用普通 GPIO 输入。

如果需要按键中断，再考虑 EXTI。

这部分目前不是电阻测量主线。

---

### 7.4 TIM —— 当前不是必需外设

本题基本测量功能 **不要求为了 ADC 而强行使用定时器**。

TIM 后续可能用于：

- 周期测量
- 固定刷新节奏
- ADC 硬件触发
- 动态扫描数码管

但这些都属于实现方式或后续优化。

当前阶段：

> **优先采用软件触发 ADC，不为了使用 TIM 而使用 TIM。**

---

### 7.5 显示接口 —— 待确定

最终需要将测得的电阻值显示出来。

显示方案暂未确定，可根据后续硬件选择：

- 数码管
- LCD
- OLED
- 其他显示模块

如果采用动态扫描数码管，可能额外使用 TIM。

## 8. 软件与硬件必须同步设计

这道题不能只写 STM32 软件。

原因是软件中的这些参数：

- ADC 计算公式
- 自动换挡阈值
- 参考电阻值
- 量程边界
- 稳定等待时间
- 滤波策略
- 校准系数

全部依赖实际模拟测量电路。

因此后续应同步推进：

```text
测量电路设计
      ↕
参考电阻选择
      ↕
量程切换电路
      ↕
ADC 配置
      ↕
自动量程算法
      ↕
电阻计算
```

不能先完全脱离硬件写完软件，再回头考虑电路。

## 10. 量程切换器件：模拟开关 vs 继电器

自动量程需要由 STM32 控制外部器件，把不同的参考电阻接入测量回路。

当前主要比较两类方案：

- CMOS 模拟开关 / 多路复用器
- 机械继电器 / 簧片继电器

这两个方案都能完成“GPIO 控制量程”的任务，但它们引入的误差机制完全不同。

---

### 10.1 模拟开关的基本模型

理想情况下：

```text
GPIO
 │
 ▼
模拟开关
 │
 ▼
Rref
 │
 ▼
测量节点
```

但实际模拟开关在导通时并不是理想短路，而存在导通电阻：

```text
Ron
```

因此真正参与分压的参考支路近似为：

```text
Rref_actual = Rref + Ron
```

例如只用于说明量级：

```text
Rref = 33Ω
Ron  = 5Ω
```

则实际支路已经接近：

```text
38Ω
```

相对于 33Ω，误差量级已经非常大。

因此：

> **低阻档最怕模拟开关的导通电阻 Ron。**

而且 Ron 往往还不是严格恒定值，它可能随：

- 模拟输入电压
- 供电电压
- 温度
- 芯片个体差异

发生变化。

所以不能简单认为：

```text
测量结果 - 固定 Ron
```

就一定能完全补偿。

---

### 10.2 为什么中阻档对 Ron 没那么敏感

如果仍假设一个若干欧姆量级的 Ron：

对于：

```text
Rref = 33Ω
```

它占比很大。

但对于：

```text
Rref = 3.3kΩ
```

同样的 Ron 相对占比就会小很多。

所以：

```text
参考电阻越小
    ↓
Ron 占总阻值比例越大
    ↓
对测量精度影响越严重
```

这也是为什么不能只看“模拟开关能不能导通”，还必须看 datasheet 中的：

- Ron
- Ron flatness
- Ron 随信号电压的变化
- Ron 随温度的变化

---

### 10.3 高阻档的问题正好反过来

到了 MΩ 级高阻测量时，几欧姆的 Ron 相对于被测阻值已经几乎可以忽略。

此时更危险的是：

> **漏电流（Leakage Current）**

高阻电阻本身通过的电流就很小，因此：

- 模拟开关 OFF 漏电
- PCB 表面漏电
- ADC 输入漏电
- 保护器件漏电
- 污渍、助焊剂残留、潮气形成的漏电路径

都可能进入有效误差预算。

因此可以先记住：

```text
低阻测量
→ 重点关注：Ron、线阻、接触电阻

高阻测量
→ 重点关注：Leakage、PCB 表面、ADC 输入、器件绝缘
```

这两个量程的主要误差源并不相同。

---

### 10.4 继电器为什么更适合第一版

继电器的量程控制链路为：

```text
STM32 GPIO
    │
    ▼
NPN / MOSFET 驱动
    │
    ▼
继电器线圈
    │
    ▼
机械触点
    │
    ▼
参考电阻
```

继电器触点闭合以后，其接触电阻通常远小于普通 CMOS 模拟开关的 Ron。

所以对于当前计划中的低阻参考档，例如：

```text
33Ω
330Ω
3.3kΩ
```

继电器更容易建立一个简单、直观、容易分析的误差模型。

对于高阻测量，继电器物理触点断开后的绝缘性能通常也更容易满足高阻测量需要。

因此当前项目第一版推荐：

> **先使用继电器完成自动量程闭环，等测量原理和软件流程跑通以后，再考虑用精密模拟开关缩小体积和功耗。**

这不是因为继电器“更先进”，而是因为第一版应优先降低系统复杂度和不确定性。

---

### 10.5 STM32 GPIO 不能直接驱动普通继电器线圈

不能直接这样连接：

```text
STM32 GPIO ───── 继电器线圈
```

原因：

- GPIO 输出电流能力有限
- 继电器线圈通常需要更大的驱动电流
- 线圈属于感性负载
- 断电时会产生反向感应电压

推荐结构：

```text
             继电器电源
                 │
              继电器线圈
                 │
                 ├──── 续流二极管
                 │
              NPN / MOSFET
                 │
                GND
                 ▲
                 │
            STM32 GPIO
```

GPIO 只负责：

> **给驱动管提供控制信号。**

真正给继电器线圈提供电流的是外部电源和驱动晶体管。

续流二极管用于吸收继电器线圈断电时产生的反向感应能量，保护驱动器件。

具体：

- 继电器线圈电压
- 线圈电流
- MOSFET / NPN 型号
- 栅极/基极电阻
- 续流二极管

必须根据最终继电器 datasheet 再确定。

---

### 10.6 继电器换档后不能马上 ADC 采样

继电器属于机械器件。

GPIO 状态变化以后，还会经历：

```text
GPIO 改变
    ↓
驱动管导通 / 截止
    ↓
继电器线圈建立 / 释放磁场
    ↓
机械触点动作
    ↓
触点可能短暂抖动
    ↓
测量节点重新建立电压
    ↓
电路稳定
    ↓
ADC 重新采样
```

因此软件不能简单写成：

```c
Range_Switch();
ADC_Read();
```

而应设计成：

```text
切换量程
    ↓
等待继电器和模拟节点稳定
    ↓
丢弃必要的首次采样（如需要）
    ↓
重新采样
    ↓
判断档位
```

等待时间不能拍脑袋固定，最终应根据：

- 继电器动作时间
- 释放时间
- 触点回跳时间
- 测量节点 RC 时间常数

共同确定。

---

### 10.7 为什么本题不在乎继电器切换速度慢

本题不是高速信号切换系统。

正常自动量程流程是：

```text
测量
 ↓
发现档位不合适
 ↓
切换一次
 ↓
重新测量
 ↓
找到合适档位
 ↓
保持当前档位连续测量
```

并不是：

```text
每做一次 ADC 转换
都切一次继电器
```

所以继电器的毫秒级动作速度对于电阻测试仪通常不是主要矛盾。

真正需要关注的是：

- 测量精度
- 稳定性
- 量程切换后的 settling
- 接触电阻
- 高阻绝缘

---

### 10.8 模拟开关并不是被淘汰

模拟开关仍然具有明显优势：

- 体积小
- 无机械磨损
- 切换快
- 功耗低
- 无触点抖动
- 控制简单

后续如果需要把设备做小，可以重新评估**精密模拟开关**。

这时不能只看“有几个通道”，而要重点阅读 datasheet：

```text
Ron
Ron flatness
OFF leakage
ON leakage
模拟输入范围
供电范围
带宽
通道间串扰
温漂
```

特别是低阻档和高阻档，选型关注点不同：

```text
低阻档
→ 优先看 Ron / Ron flatness

高阻档
→ 优先看 leakage / insulation
```

后续必须结合：

- 原题各量程准确范围
- 参考电阻精度
- 继电器接触电阻
- 测试线电阻
- ADC 总误差
- 校准方案

重新计算误差预算后才能定案。

---

### 10.11 一个已经出现的重要问题：100Ω 档的两线测量误差

当被测电阻进入几十欧姆到一百欧姆量级时：

- 测试线电阻
- 插座接触电阻
- 夹子接触电阻
- 继电器触点电阻
- PCB 走线电阻

开始不能完全忽略。

因此后续需要单独做一次 **100Ω 档误差预算**。

如果误差预算无法满足题目精度，再评估：

- 软件零点校准
- 空载 / 短路校准
- 更低接触电阻器件
- Kelvin 四线制测量

但当前阶段不提前上四线制，先用最小复杂度验证基本测量链路。

---

### 10.12 当前结论

当前量程切换方案的设计原则：

```text
第一版目标
    ↓
先把测量闭环做通
    ↓
优先降低误差模型复杂度
    ↓
采用继电器切换参考电阻
    ↓
ADC + GPIO + 继电器驱动跑通
    ↓
完成自动量程
    ↓
再评估精密模拟开关优化
```

核心认识：

> **低阻档主要防 Ron / 线阻 / 接触电阻；高阻档主要防 Leakage。**

这两类误差必须分别处理，不能用同一种直觉看待所有量程。

## 15. 本地环境

首次克隆时需要同时拉取标准库 submodule：

```bash
git clone --recurse-submodules https://github.com/shalebao3/embed-2011G-SimpleAutomaticResistorTester.git
```

如果已经 clone，但标准库目录为空：

```bash
git submodule update --init --recursive
```

macOS 开发环境需要能够执行：

```bash
arm-none-eabi-gcc --version
cmake --version
ninja --version
```

构建：

```bash
cmake --preset Debug -S firmware
cmake --build --preset Debug
```

构建产物名称跟随当前 CMake 工程名：

```text
embed-2011G-SimpleAutomaticResistorTester.elf
embed-2011G-SimpleAutomaticResistorTester.hex
embed-2011G-SimpleAutomaticResistorTester.bin
embed-2011G-SimpleAutomaticResistorTester.map
```
